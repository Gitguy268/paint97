# Clippy assets

`map.png`, `agent.json` and `sounds.json` are the sprite sheet, animation data
and sounds of Clippy, the Microsoft Office assistant.

**The artwork, animations and sounds belong to Microsoft. They are not covered
by this project's MIT licence, and nobody here can grant you rights to them.**
"Clippy" and the Office Assistants are Microsoft's. This project is not
affiliated with, endorsed by or sponsored by Microsoft.

The data comes from two open-source projects, in the format they defined:

- [pithings/clippy](https://github.com/pithings/clippy) (published on npm as
  `clippyjs`), MIT, see `LICENSE-pithings-clippy.txt`
- [smore-inc/clippy.js](https://github.com/smore-inc/clippy.js), MIT, see
  `LICENSE-smore-clippy.js.txt`

This project is not affiliated with or endorsed by either of those projects.

Those two MIT licences cover the code and the data format of those projects.
They do not cover the character artwork either: both projects say it remains
Microsoft's, and that it was extracted with
[Double Agent](https://doubleagent.sourceforge.net/) by Cinnamon Software.
